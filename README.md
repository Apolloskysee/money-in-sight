# Money in Sight - Умный контроль финансов

Полнофункциональное веб-приложение для управления личными финансами.

## 🌟 Особенности
- Учет доходов и расходов
- Аналитика и отчеты
- Финансовые цели
- Учет долгов
- Премиум подписка
