## 🚀 Что нужно сделать дальше

### 1. Установить переменные окружения
```env
EMAILJS_SERVICE_ID=service_xxxxx
EMAILJS_TEMPLATE_ID=template_xxxxx
EMAILJS_PUBLIC_KEY=public_key_xxxxx
FIREBASE_ADMIN_CREDENTIALS={"type":"service_account",...}
FIREBASE_SERVICE_ACCOUNT_JSON={"type":"service_account",...}
NODE_ENV=production
```

### 2. Настроить EmailJS
- Создать аккаунт на [emailjs.com](https://www.emailjs.com/)
- Добавить email сервис (Gmail/SMTP)
- Создать шаблон для писем верификации
- Получить ключи в Dashboard → Keys

### 3. Протестировать на локальной машине
```bash
npm run dev
# Перейти на http://localhost:8888
# Заполнить форму регистрации
# Проверить консоль на код верификации
```

### 4. Задеплоить на production
```bash
git push
# Netlify автоматически задеплоит
# Проверить логи функций
```

## 📞 Часто задаваемые вопросы

### Q: Почему используется 6-значный код?
**A:** Это стандарт для email верификации (достаточно безопасно, легко запомнить)

### Q: Почему 10 минут для срока действия?
**A:** Баланс между безопасностью и удобством пользователя

### Q: Почему максимум 3 попытки?
**A:** Защита от brute-force атак

### Q: Что если пользователь потеряет письмо?
**A:** Может нажать "Отправить код повторно" после 60 сек

### Q: Где хранятся коды?
**A:** В Firestore коллекции `verificationCodes`

### Q: Будет ли работать в offline режиме?
**A:** Нет, нужен интернет для отправки email и Firestore
