## 📝 Процесс регистрации (3 шага)

### Шаг 1️⃣: Регистрация
```
1. Нажмите "Зарегистрироваться"
2. Введите:
   - Имя: Ваше имя
   - Email: ваша@почта.com
   - Пароль: Сложный пароль
   - ✓ Согласие с условиями
3. Нажмите "Создать аккаунт"

Результат: Откроется модаль верификации email
```

### Шаг 2️⃣: Получить код верификации
```
ВАРИАНТ A (Локальная разработка):
- Откройте консоль браузера (F12)
- Ищите: "Code for ваша@почта.com: 123456"
- Скопируйте 6-значный код

ВАРИАНТ B (Продакшен):
- Проверьте папку входящих писем
- Откройте письмо от приложения
- Скопируйте код из письма
```

### Шаг 3️⃣: Подтвердить email
```
1. В модали верификации введите 6-значный код
2. Нажмите "Подтвердить код"

Результат: 
- Модаль закроется
- Приложение откроется автоматически
- Вы вошли как новый пользователь ✅
```

## 🆘 Решение типичных проблем

### ❌ "Код не отправляется на почту"
```
Это НОРМАЛЬНО при локальной разработке!

Код выводится в консоль браузера.
Проверьте F12 → Console → ищите "Code for..."
```

### ❌ "Модаль верификации не открывается"
```
Решение:
1. Обновите страницу (F5)
2. Попробуйте регистрацию снова
3. Проверьте консоль на ошибки (F12)
```

### ❌ "После входа приложение пусто"
```
Решение:
1. Дождитесь полной загрузки (может быть 3-5 сек)
2. Обновите страницу (F5)
3. Проверьте консоль на ошибки загрузки данных
```

### ❌ "Ошибка при регистрации: 'Email уже используется'"
```
Решение:
1. Используйте другой email
2. ИЛИ если это ваш email:
   - Выполните вход вместо регистрации
   - Если забыли пароль - нужна функция восстановления
```

### ❌ "Попытки ввода кода закончились"
```
Что произойдет:
1. После 3 неверных попыток код удаляется
2. Нажмите "Вернуться" к регистрации
3. Нажмите "Переотправить код"
4. Дождитесь 60 секунд
5. Нажмите "Переотправить код" снова
```
