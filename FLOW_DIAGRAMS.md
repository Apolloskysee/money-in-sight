```
│          УПРАВЛЕНИЕ СОСТОЯНИЕМ                                  │
└─────────────────────────────────────────────────────────────────┘

WINDOW._REGISTRATIONSTATE:
├─ inProgress: boolean
│  ├─ true  → Регистрация идет, не показывать приложение
│  └─ false → Можно показывать приложение

│  └─ ID пользователя для верификации

└─ skipVerificationCheck: boolean

├─ email: string
├─ emailVerified: boolean
│  ├─ false → Требуется верификация
│  └─ true  → Может использовать приложение
├─ name: string
├─ lastLogin: timestamp
└─ createdAt: timestamp


FIRESTORE VERIFICATIONCODES DOCUMENT:
├─ userId: string (ID документа)
├─ code: string (6 цифр)
├─ expiresAt: timestamp (текущее время + 10 минут)
├─ attempts: number (макс 3)
└─ createdAt: timestamp
```

```
СОСТОЯНИЕ: Не зарегистрирован
├─ Видит: Форму регистрации, форму входа

СОСТОЯНИЕ: Зарегистрирован, email не верифицирован
├─ Видит: Модаль верификации email
├─ Может: Вводить код, переотправлять код, вернуться к регистр.
└─ НЕ может: Видеть приложение, его данные заблокированы

СОСТОЯНИЕ: Email верифицирован, вошел в приложение
├─ Видит: Полное приложение со всеми функциями
├─ Может: Добавлять данные, редактировать профиль, выходить
└─ НЕ может: Видеть данные других пользователей

СОСТОЯНИЕ: Вышел из приложения
├─ Видит: Форму входа
├─ Может: Входить заново, регистрироваться с новым email
└─ НЕ может: Видеть свои данные
```

## 🔐 ТОЧКИ ЗАЩИТЫ

```
┌─────────────────────────────────────────────────────────────────┐
│           МНОГОУРОВНЕВАЯ ЗАЩИТА                                 │
└─────────────────────────────────────────────────────────────────┘

УРОВЕНЬ 1: Валидация на клиенте
  ├─ Email формат
  ├─ Пароль сложность (опция)
  └─ Все поля заполнены

УРОВЕНЬ 2: Firebase Authentication
  ├─ Создание аккаунта с уникальным email
  ├─ Хеширование пароля
  └─ Управление сессией токенов

УРОВЕНЬ 3: Email верификация
  ├─ Отправка кода на email
  ├─ Максимум 3 попытки ввода
  └─ Блокировка доступа до верификации

УРОВЕНЬ 4: Firestore правила (serverTrust)
  ├─ Пользователь может читать только свои документы
  ├─ Пользователь может писать только в свои документы
  ├─ verificationCodes доступны только владельцу
  └─ Default: отказ для всех остальных

УРОВЕНЬ 5: Состояние приложения
  ├─ onAuthStateChanged проверяет emailVerified
  ├─ initializeAuth блокирует доступ если не верифицирован
  └─ showApp() никогда не вызывается для неверифицированных
```
