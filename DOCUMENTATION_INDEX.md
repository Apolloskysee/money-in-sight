## 🚀 Как развернуть

### 1️⃣ Локальная разработка
```
1. npm install
2. Скопировать Firestore правила из [FIRESTORE_RULES.md](FIRESTORE_RULES.md)
3. npm start
4. Открыть http://localhost:5000
```

### 2️⃣ Продакшен (Netlify)
```
1. Убедиться что Firestore правила установлены
2. Настроить email функции в netlify/functions/
3. Развернуть: netlify deploy
4. Проверить в консоли браузера логи Firebase
```
