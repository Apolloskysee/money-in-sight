## 🚀 ПЕРВЫЕ ШАГИ

### Шаг 1: Firestore правила (КРИТИЧНО!)
```
1. Откройте Firebase Console → Firestore Database → Rules
2. Скопируйте ВСЕ содержимое из FIRESTORE_RULES.md
3. Нажмите "Publish"
4. Дождитесь "Rules updated successfully"
```

### Шаг 2: Запустить приложение
```bash
npm install
npm start
# Откроется http://localhost:5000
```

### Шаг 3: Зарегистрироваться
```
1. Нажмите "Зарегистрироваться"
2. Заполните форму
3. Получите код из консоли браузера (F12)
4. Подтвердите код
5. Используйте приложение!
```

## 🆘 ПРОБЛЕМЫ?

### Если что-то не работает:

1. **Проверьте Firestore правила**
   - Откройте Firebase Console → Firestore → Rules
   - Убедитесь что содержимое из [FIRESTORE_RULES.md](FIRESTORE_RULES.md) скопировано и опубликовано

2. **Смотрите консоль браузера**
   - Нажмите F12 → Console
   - Ищите логи операций
   - Ищите сообщения об ошибках

3. **Читайте полную документацию**
   - [COMPLETE_AUTH_FLOW.md](COMPLETE_AUTH_FLOW.md) - Раздел "Возможные проблемы и решения"

4. **Проверьте Firestore данные**
   - Firebase Console → Firestore → Data
   - Убедитесь что данные сохраняются
