# Улучшения системы верификации email при регистрации

## Описание

В проекте была реализована полноценная система верификации электронной почты при регистрации пользователей. Система отправляет 6-значный код на почту пользователя, и пользователь должен подтвердить код для завершения регистрации.

## 🔄 Процесс регистрации с верификацией

1. **Пользователь заполняет форму регистрации**
   - Имя
   - Email
   - Пароль
   - Согласие с условиями

2. **Нажимает "Начать 14 дней бесплатно"**
   - Создается учетная запись в Firebase Auth
   - Генерируется 6-значный код верификации
   - Код сохраняется в Firestore с временем истечения (10 минут)
   - Email отправляется на указанный адрес

3. **Открывается модаль верификации**
   - Пользователю предлагается ввести код из письма
   - Кнопка повторной отправки отключена на 60 секунд
   - Максимум 3 попытки ввода неправильного кода

4. **Проверка кода**
   - Сравнивается введенный код с сохраненным
   - Проверяется срок действия кода
   - Обновляется статус пользователя в Firestore
   - Удаляется использованный код

5. **Успех**
   - Пользователь получает доступ к приложению
   - Email отмечается как проверенный
   - Загружаются данные приложения

## 📧 Email сообщение

Email отправляется через EmailJS с следующей информацией:
- **To:** Email пользователя
- **Subject:** Подтверждение регистрации в Money in Sight
- **Body:** 6-значный код верификации
- **Type:** registration

### Пример настройки EmailJS переменных окружения:
```
EMAILJS_SERVICE_ID=service_xxxxx
EMAILJS_TEMPLATE_ID=template_xxxxx
EMAILJS_PUBLIC_KEY=public_key_xxxxx
```

## 🧪 Режимы работы

### Режим разработки (NODE_ENV !== 'production')
- Код выводится в консоль браузера и сервера
- Код сохраняется в Firestore для тестирования
- Email не отправляется реально

### Режим Production
- Используется EmailJS для отправки email
- Email отправляется на реальный адрес
- Код сохраняется в Firestore для проверки
- Все чувствительные данные скрыты

## 🚀 Как использовать

### 1. Убедитесь, что все зависимости установлены:
```bash
npm install
```

### 2. Установите переменные окружения в `.env`:
```
FIREBASE_ADMIN_CREDENTIALS={"type":"service_account",...}
EMAILJS_SERVICE_ID=service_xxxxx
EMAILJS_TEMPLATE_ID=template_xxxxx
EMAILJS_PUBLIC_KEY=public_key_xxxxx
NODE_ENV=development
```

### 3. Протестируйте регистрацию:
- Откройте приложение
- Нажмите "Начать бесплатно"
- Заполните форму регистрации
- Проверьте почту на получение кода
- Введите код в модали верификации

## ⚠️ Известные ограничения и улучшения

### Текущие ограничения:
- Коды хранятся в Firestore (можно использовать Redis для масштабирования)
- Нет возможности отправить код повторно с другого адреса email

### Возможные улучшения:

2. Использовать Redis для кеширования кодов

4. Добавить возможность отправки кода несколько раз

## 📞 Поддержка

Если возникли проблемы:

1. **Код не приходит на email:**
   - Проверьте спам-папку
   - Убедитесь, что EmailJS ключи верны
   - Проверьте логи сервера

2. **Ошибка "Превышено максимальное число попыток":**
   - Нажмите "Назад к регистрации"
   - Попробуйте зарегистрироваться снова

3. **Код истек:**
   - Нажмите "Отправить код повторно"
   - Код истекает через 10 минут
