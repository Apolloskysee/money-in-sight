## ✅ ШАГА 1: Подготовка Firebase Console (2 минуты)

### 1.1 Открыть Firestore правила
```
1. Откройте https://console.firebase.google.com
2. Выберите проект "finance-78bce"
3. Перейдите Firestore Database → Rules (вкладка Rules)
4. Удалите текущие правила (или оставьте как есть)
5. Скопируйте ВСЕ содержимое из файла: FIRESTORE_RULES.md
```

### 1.2 Вставить правила
```
1. Выделите весь текст правил из FIRESTORE_RULES.md
2. Вставьте в текстовое поле Firebase Console
3. Нажмите кнопку "Publish" (публиковать)
4. Дождитесь сообщения "Rules updated successfully"
```

**ВАЖНО:** Без этих правил регистрация не будет работать!

## ✅ ЭТАП 3: Первая регистрация (3 минуты)

### 3.1 Откройте консоль браузера
```
1. Нажмите F12
2. Перейдите на вкладку "Console"
3. Оставьте консоль открытой (будет нужна для кода)
```

### 3.2 Регистрация
```
1. На главной странице нажмите "Зарегистрироваться"
2. Заполните форму:
   - Имя: "Тестовый пользователь"
   - Email: "test@example.com"
   - Пароль: "Test@12345"
   - ✓ Согласие с условиями
3. Нажмите "Создать аккаунт"
```

### 3.3 Получить код верификации
```
1. В консоли браузера (F12 → Console) ищите строку:
   "Code for test@example.com: 123456"
   
2. Скопируйте 6-значный код
3. Ожидайте появления модали верификации на экране
```

**Если консоль чистая:**
- Обновите страницу (F5)
- Попробуйте регистрацию еще раз
- Проверьте что код отправляется в Firestore

### 3.4 Подтвердить email
```
1. В открывшейся модали "Подтверждение email"
2. Вставьте код верификации (из шага 3.3)
3. Нажмите "Подтвердить код"
4. Модаль закроется и откроется приложение
```

**Готово!** ✅ Первая регистрация успешна!

## ⚠️ ЧАСТЫЕ ПРОБЛЕМЫ И РЕШЕНИЯ

### ❌ Ошибка: "Firestore Database is not initialized"
```
Решение:
1. Проверьте что Firebase Console открыт
2. Убедитесь что правила скопированы корректно
3. Обновите страницу браузера (F5)
4. Очистите кэш браузера (Ctrl+Shift+Delete)
```

### ❌ Код не выводится в консоль
```
Решение:
1. Проверьте что консоль (F12) открыта ДО регистрации
2. Обновите страницу (F5)
3. Попробуйте регистрацию с другим email
4. Проверьте Firestore → verificationCodes коллекция
```

### ❌ Приложение остается пусто после верификации
```
Решение:
1. Дождитесь 3-5 секунд (загружаются данные)
2. Обновите страницу (F5)
3. Проверьте консоль на ошибки (F12 → Console)
4. Убедитесь что emailVerified = true в Firestore
```

### ❌ После входа видно только формы, нет дашборда
```
Решение:
1. Дождитесь полной загрузки (может быть 2-3 сек)
2. Обновите страницу (F5)
3. Проверьте консоль браузера на ошибки
4. Убедитесь что loadDashboardData работает
```

### ❌ Ошибка "Permission denied" при сохранении кода
```
Решение:
1. Проверьте что правила из FIRESTORE_RULES.md скопированы
2. Особенно важна секция verificationCodes
3. Нажмите "Publish" в Firebase Console
4. Дождитесь применения правил (обычно несекунд)
```
