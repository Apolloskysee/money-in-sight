# 🚀 Исправление регистрации - ИНСТРУКЦИЯ

## ✅ Что было исправлено:

### 1. ❌ Ошибка: "Missing or insufficient permissions" при сохранении кода верификации
**Причина:** Firestore правила не позволяли пользователю писать в коллекцию `verificationCodes`

**Решение:**
- ✅ Обновлены Firestore правила 
- ✅ Добавлены явные правила для коллекции `verificationCodes`
- ✅ Правила теперь работают на основе ID документа (userId)

### 2. ⚠️ Проблема: Пользователь автоматически входил при регистрации
**Проблема:** После создания профиля пользователь видел приложение, хотя email не верифицирован

**Решение:**
- ✅ Добавлен проверка `emailVerified` в `initializeAuth()`
- ✅ После регистрации пользователь логаутится
- ✅ Показывается модаль верификации email
- ✅ Приложение открывается только после верификации

## 📋 ПОРЯДОК РАБОТЫ РЕГИСТРАЦИИ (новый):

```
1. Пользователь заполняет форму регистрации
   ↓
2. registerUser() создает аккаунт в Firebase Auth
   ↓
3. Сохраняется профиль в Firestore (emailVerified = false)
   ↓
4. Генерируется и сохраняется код верификации
   ↓
5. Отправляется письмо с кодом на почту
   ↓
6. ⚠️ ПОЛЬЗОВАТЕЛЬ ЛОГАУТИТСЯ (signOut)
   ↓
7. Открывается модаль "Подтверждение email"
   ↓
8. Пользователь вводит код из письма
   ↓
9. Код проверяется и удаляется из Firestore
   ↓
10. Устанавливается emailVerified = true в Firestore
   ↓
11. onAuthStateChanged срабатывает → проверяет emailVerified
   ↓
12. Если emailVerified = true → showApp()
   ↓
13. Пользователь видит приложение ✅
```

## 🛠️ ОБЯЗАТЕЛЬНЫЕ ШАГИ:

### Шаг 1: Обновите Firestore правила

1. Откройте [Firebase Console](https://console.firebase.google.com)
2. Выберите проект "finance-78bce"
3. Firestore Database → Rules
4. Скопируйте ВСЕ правила из файла [FIRESTORE_RULES.md](FIRESTORE_RULES.md)
5. Вставьте в редактор
6. Нажмите **"Publish"**
7. Подождите 30 сек - должно появиться "Rules published successfully"

**⚠️ ВНИМАНИЕ:** Без этого шага регистрация не будет работать!

### Шаг 2: Полностью очистите браузер

1. Откройте DevTools (F12)
2. Перейдите на вкладку Application
3. Storage → Clear site data
4. Включите "Cookies" и "Storage"
5. Нажмите "Clear"

Или просто: **Ctrl+Shift+Delete** → Clear all

### Шаг 3: Перезагрузите страницу

- **Ctrl+Shift+R** (полная перезагрузка)
- Или закройте и заново откройте сайт

### Шаг 4: Тестируйте регистрацию

1. Нажмите "Начать бесплатно"
2. Введите:
   - Имя: Тестовый пользователь
   - Email: test@example.com
   - Пароль: Test123456
   - Согласитесь с условиями
3. Нажмите "Зарегистрироваться"

**Ожидаемый результат:**
- ✅ Нет ошибок в консоли
- ✅ Вы видите модаль "Подтверждение email"
- ✅ В консоли видите код (в режиме разработки)
