### 4. 🔐 Безопасность при удалении аккаунта

**Процесс:**
1. Пользователь вводит email для подтверждения
2. Email отправляется на серверную функцию `delete-user.js`
3. Admin SDK удаляет:
   - Пользователя из Firebase Auth
   - Документ пользователя из Firestore
   - Все транзакции
   - Все цели
   - Все задачи
   - Все коды верификации
4. Пользователь логируется и перенаправляется на главную страницу

**Почему серверная функция безопаснее:**
- ✅ Использует Admin SDK (полный доступ)
- ✅ Атомарные операции (все или ничего)
- ✅ Не зависит от прав пользователя
- ✅ Автоматически удаляет все связанные данные

### 5. 📊 Процесс регистрации (полный цикл)

```
1. Пользователь заполняет форму
   ↓
2. validateRegistration() проверяет данные
   ↓
3. registerUser() создает аккаунт с retry logic
   ├─ Создает пользователя в Firebase Auth
   ├─ Сохраняет профиль в Firestore (с retry)
   ├─ Генерирует код верификации
   ├─ Сохраняет код в Firestore
   └─ Отправляет письмо на сервер
   ↓
4. Открывается модаль верификации
   ↓
5. Пользователь вводит код из письма
   ↓
6. handleVerificationSubmit() проверяет код
   ├─ Проверяет совпадение кода
   ├─ Проверяет срок действия
   ├─ Считает попытки (макс 3)
   └─ Обновляет emailVerified в Firestore
   ↓
7. showApp() - приложение загружается
```
