## 🎯 Сценарии регистрации и входа

### СЦЕНАРИЙ 1️⃣: Новая регистрация → Верификация email → Вход

#### Шаг 1: Открыть приложение
```
1. Откройте http://localhost:5000 (или ваш сервер)
2. Приложение должно показать экран приветствия с формой регистрации
3. В консоли браузера должны быть логи инициализации Firebase
```

**Проверка в консоли:**
```
✅ Загрузка модуля аутентификации...
✅ Firebase успешно инициализирован
✅ Аутентификация инициализирована
🚪 Пользователь вышел (при первом запуске)
```

---

#### Шаг 2: Регистрация нового пользователя
```
1. Нажимаем на "Зарегистрироваться" (или откроется регистрация сразу)
2. Вводим данные:
   - Имя: "Иван Тестов"
   - Email: "test123@yandex.ru"
   - Пароль: "Test@123456"
   - Соглашение: галка ✓
3. Нажимаем "Создать аккаунт"
```

**Проверка в консоли:**
```
📝 Начало процесса регистрации для: test123@yandex.ru
✨ Регистрация пользователя: test123@yandex.ru (попытка 1/3)
🔒 Профиль пользователя сохранен в Firestore
📧 Код верификации сохранен в Firestore
✅ Код отправлен на почту
✅ Пользователь успешно зарегистрирован: <uid>
🚪 Пользователь логаутен - требуется верификация email
✅ Регистрация завершена, требуется верификация: true
```

**На экране:**
- Модаль регистрации закрывается
- Появляется уведомление: "✅ Код подтверждения отправлен на test123@yandex.ru. Проверьте почту."
- Открывается модаль верификации email

## ⚠️ Возможные проблемы и решения

### Проблема: "Email код не отправляется"
**Решение:**
1. Проверьте Firestore правила (должны разрешить запись в verificationCodes)
2. Проверьте, что sendgrid или другой email-сервис настроен в Netlify функциях
3. В DEV режиме код выводится в консоль - это нормально

### Проблема: "Регистрация зависает"
**Решение:**
1. Проверьте консоль браузера на ошибки
2. Убедитесь что Firebase инициализирован (должна быть запись "✅ Firebase успешно инициализирован")
3. Проверьте подключение к интернету

### Проблема: "После верификации приложение не открывается"
**Решение:**
1. Проверьте, что Firestore правила позволяют読/писать в коллекцию "users"
2. Убедитесь что `emailVerified` флаг обновлен на true в Firestore
3. Проверьте консоль браузера на ошибки
4. Обновите страницу вручную (F5)

### Проблема: "Вход зависает на загрузке"
**Решение:**
1. Убедитесь что `window.UI.loadDashboardData` и `window.UI.loadProfileData` работают
2. Проверьте консоль на ошибки при загрузке данных
3. Убедитесь что у пользователя есть доступ к коллекциям в Firestore

### Проблема: "Модаль входа закрывается слишком быстро"
**Решение:**
1. Это нормально - добавлена задержка 800ms для загрузки данных
2. Если данные загружаются дольше - увеличьте задержку в `handleLoginSubmit()` на несколько миллисекунд

## 📊 Структура данных Firestore

### Коллекция: users
```javascript

  uid: "firebase-uid",
  name: "Иван Тестов",
  email: "test@example.com",
  emailVerified: true,           // ← КРИТИЧНО для доступа к приложению

  verifiedAt: timestamp,         // optional
  createdAt: timestamp,

}
```

```javascript
// Документ с ID = userId пользователя

  createdAt: timestamp
}
```
